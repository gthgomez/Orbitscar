In the ruleset 0.10.0 reactive timing corpus (6,160 runs, seed base 30,000), counter-read won 76.1% versus immediate mass 74.5%, with 0.30 more casualties and 0.87 more alloy per battle. Raid persistence tests cover schema 10 migration and all nine archetype/intensity combinations.
