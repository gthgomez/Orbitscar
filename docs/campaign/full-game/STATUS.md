Follow-up conditional policy experiments did not improve aggregate win rate and were not retained. Recent broad balance gates pass: line-rigger sweep, zero-casualty universal composition, defended all-in, approach variation, and commander impact. Raid persistence tests cover schema 10 migration and all nine archetype/intensity combinations. All 114 test assertions across 14 files pass, including the new extractor-capacity, maximum structure-level, and terminal-command regressions; all three typechecks, content validation, and production web build pass. Bundle is 1,343.13 KB minified (373.13 KB gzip) with Vite's chunk-size warning. Coverage includes touch canvas placement and pan policy, onboarding, economy/progression, defense raids, authority PvE/rival attacks, live commands, retreat, report/replay, migration/tamper handling, and mobile layout. Human blind-playtest evidence remains unverified.

The local authority server is single-process file storage without network authentication and needs an authenticated deployment boundary for remote use. Vite retains its >500 KB main-chunk warning. Human blind-playtest evidence remains unavailable.
- **Next actions:** request review of the certified PR and schedule blind human playtesting. Adversarial review found and drove fixes for extractor spam, mobile canvas occlusion/scroll behavior, duplicate relay construction, over-level modules, post-terminal reinforcement, per-frame full battle saves, and authority actions silently dropping while a request was pending.
