# Two-Year Failure Pre-Mortem

**Status:** ACTIVE

| Failure | Earliest warning signal | Metric/evidence | Prevention | Contingency |
|---|---|---|---|---|
| Combat is not fun | second attack rate is low | <50% start a second attack | cut meta and iterate combat | pivot to scenario tactics |
| Feels like imitation | players use reference names | similarity review or “reskin” feedback | clean-room ledger and asset gate | redesign expression before public test |
| No audience | weak blind recruitment conversion | <20% invite-to-play | narrow pitch and recruit strategy communities | stop MMO spend |
| Art too slow | one asset takes >2 days | production throughput log | silhouette-first atlases | ship debug/flat style |
| Retention dies | reports not revisited | D7/D21 replay and second-plan metrics | report learning and scenario variety | single-player premium pivot |
| Territory oppressive | map concentrated early | top alliance >55% nodes | upkeep, decay, protected lanes | cap territory mode |
| Monetization harms trust | fairness complaints in mock store | power-equivalence audit fails | cosmetics-only rules | remove convenience sales |
| Backend costs explode | cost per active player grows faster than retention | infra cost / WAU | one service + Postgres first | reduce tick/season scope |
| Browser performance fails | low-end mobile stalls | p95 frame time / load time | asset budget and effects mode | browser-only 2D cut |
| Bots ruin PvP | impossible event patterns | anomaly rate, report flags | server validation and rate limits | suspend ranked PvP |
| Alliances become toxic | member churn after operations | moderation reports, officer time | narrow roles and protected solo path | disable public chat |
| Onboarding overloads | tutorial exits before first attack | step drop-off | one concept per beat | remove systems from first session |
| Content burden explodes | new season needs bespoke system | content hours/season | data-driven modifiers | extend season, cut feature |
| Android quality poor | device-specific input/layout faults | crash-free sessions, form-factor matrix | responsive QA from slice | web-first beta |
| Solo players churn | no solo attack cadence | solo D7 vs alliance D7 | solo relay contracts | make alliance mode optional event |
| Progression deadlocks | negative/empty resource states | simulator property failures | bounded costs and repair budget | grant recovery resources |
| Leadership bottleneck | every operation needs one person | order completion by role | asynchronous orders and defaults | simplify territory |
| Data loss | replay/result mismatch | migration/backups restore tests | versioned snapshots and drills | freeze writes and restore |
| Project loses focus | backlog adds systems, not evidence | % work tied to gate | kill criteria and decision log | pause and re-evaluate |
