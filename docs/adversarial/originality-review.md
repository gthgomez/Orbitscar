## Rejection rule

Any asset or screenshot that can be described as “the Edgeworld version of X with new colors” is rejected. Reviewers must be able to explain the work using Project Orbitscar’s fiction, silhouettes, materials, and rules without reference to Edgeworld.

## Current implementation review

The closed-alpha implementation uses Orbitscar's orbital salvage fiction, relay-sector graph, original unit/building names, original SVG and procedural art, and its own information hierarchy and event language. The reviewed build showed no one-to-one expressive counterpart or copied presentation. Its persistent base, scouting, constrained deployment, autonomous combat, reinforcement choices, reports, and connected territory are broad genre principles retained from the transformation ledger. No Edgeworld code, assets, maps, text, faction names, lore, or exact tuning values were imported. Human side-by-side similarity review remains unverified; trademark, domain, copyright, and trade-dress clearance still require qualified review before public release.

## Legal boundary

This is an internal design control, not a legal opinion. Trademark clearance, copyright review, trade-dress analysis, and release counsel remain required before public branding or distribution.
