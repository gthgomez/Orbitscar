# First Combat Blind-Test Protocol

This is a later human test, not a claim that external testing has occurred.

1. Give a tester one uncoached attack attempt.
2. Ask them to describe what each unit appeared to target and why.
3. Give them a second attempt and ask them to change exactly one tactical decision.
4. Ask what changed in the result and whether they would try again.

Record, without leading questions:

- targeting comprehension;
- whether range rings and deployment zones were noticed;
- whether deployment location appeared to matter;
- whether reinforcement timing appeared to matter;
- whether commander timing appeared to matter;
- whether the tester wanted another attempt.

Do not count developer observation as validation. A meaningful next gate is that at least 60% of testers can explain one target counter and at least 60% choose a second attempt, while the researcher can reproduce the stated tactical change in the headless scenario.
