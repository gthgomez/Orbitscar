# Orbitscar presentation asset boundary

Gameplay IDs remain stable and are not renderer file paths. The first original vector slice is mapped in `apps/web/public/art/orbitscar/asset-manifest.json`.

The manifest records the presentation asset ID, gameplay IDs, file, dimensions, source/provenance, license status, and replacement status. It is intentionally small: command relay, extractor, arc projector, two unit silhouettes, and a deployment marker. The Phaser debug scene remains geometry-first until measured asset integration demonstrates a benefit.

All current pack entries are hand-authored SVGs created for this prototype. No external screenshots, ripped art, audio, or player-facing inspiration references are used.
