# Project Orbitscar — AI-Assisted Asset Pipeline

**Status:** PROCESS V0.1

## Flow

Reference principles → original prompt → concept variants → similarity review → style normalization → transparent extraction → directional/animation pass → engine import → validation → provenance receipt.

## Safeguards

- Never feed copyrighted Edgeworld screenshots, SWFs, extracted art, logos, portraits, or copied UI into a generator.
- Prompts describe our materials, geometry, function, and fictional world; they do not request “like Edgeworld” or a named artist.
- A reviewer checks silhouette, palette, composition, icon geometry, and distinctive resemblance before an asset can enter the game.
- Generated outputs stay in quarantine until metadata is complete.
- If a reference is used, record only generalized design principles and the transformation intent, not a tracing target.
