# Orbitscar documentation index

This directory holds the product, architecture, research, and process records for
Project Orbitscar, a local prototype. Scope boundaries: alliances, live operations,
monetization, and a persistent backend are deliberately deferred; the current gate
is a coherent local colony-to-breach loop.

## Current product and process documents

- `adversarial/` — pre-mortem, originality review, product red team, scope review.
- `architecture/` — ADR, rendering and combat-simulation decisions, data model, shared tooling policy.
- `art/` — art direction and asset pipeline/budget records.
- `decisions/` — decision log.
- `design/` — game design document and per-system design records.
- `economy/` — economy model and monetization options (exploratory, not committed scope).
- `infrastructure/` — infrastructure notes.
- `playtest/` — human blind-test protocol, observation form, session checklist.
- `preproduction/` — preproduction review and successor-scope material.
- `research/` — Edgeworld archaeology, inspiration-transformation ledger, market thesis and related research.
- `roadmap/` — master roadmap and agent backlog.
- `security/` — game threat model.
- `testing/` — testing records.
- `ux/` — UX records.

## Provenance and historical material

- `RECOVERY_MANIFEST.md` — provenance classification of the artifacts recovered during the 2026-08-30 repository separation.
- `recovered/legacy/` — preserved prior-generation implementation and verification records.
- `history/recovery/` — dated recovery and foundation reports (historical record, not current status). See its [index](history/recovery/README.md).

## Not legal conclusions

The "clean-room" terminology used across these documents describes the independent
implementation and recovery process. The originality review in `adversarial/originality-review.md`
is explicitly marked preliminary and is not legal advice or legal clearance.
